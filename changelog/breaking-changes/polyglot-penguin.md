`WorkflowHistory::to_json` and `WorkflowHistory::from_json` now use the proto3 JSON mapping, so histories exported with `temporal workflow show --output json` can be loaded for `WorkflowReplayer`, and histories written by the Rust SDK can be read by the other SDKs' replayers. JSON written by earlier releases no longer loads. With the `serde_serialize` feature, this also applies to the `temporal.api.history` protos and the packages they reference.
